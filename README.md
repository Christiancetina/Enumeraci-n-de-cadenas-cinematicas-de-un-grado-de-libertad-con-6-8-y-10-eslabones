# Enumeraci-n-de-cadenas-cinematicas-de-un-grado-de-libertad-con-6-8-y-10-eslabones
 Este es un programa computacional que sirva para obtener el número de cadenas cinemáticas de un grado de libertad con 6, 8 y 10 eslabones.  El programa Imprime de forma clara y ordenada el número total de cadenas y el desglose específico por cada familia de eslabones calculada .
